# Data360 Beast

Data360 Beast is a field-tested operating model for Salesforce Data 360 work:
official docs on demand, OpenAPI-first API lookup, live validation recipes, and
lean specialist skills that know where truth lives.

## What This Site Explains

- The architecture we built.
- How the API cookbook was tested.
- What improved from the earlier skill set.
- Where the remaining frontier is.

GitHub Pages source lives in `docs/`.

## Public Boundary

The raw local Salesforce Help exports and generated API catalogs are intentionally
not published in this repository. The public page summarizes the system and
links the operating model without copying official Salesforce documentation or
lab-specific working data.
