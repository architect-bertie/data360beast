# API Cookbook

This page is retained as a compatibility entry point. The old public cookbook
has been demoted because it was too thin to be a true implementation guide.

Use [`proof-ledger.md`](proof-ledger.md) for public-safe tested evidence,
readback signals, caveats, and promotion status.

Full golden-path scenarios, synthetic journeys, payload experiments, traces, and
future cookbook candidates belong in
[`data360beast-labs`](https://github.com/architect-bertie/data360beast-labs).

## Current Rule

Do not invent payload fields. Use official docs or OpenAPI for shape, use the
proof ledger for known behavior and caveats, and use Labs for exploratory or
end-to-end scenario work.
